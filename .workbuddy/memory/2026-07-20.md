## 意图识别对比实验：BERT 微调 vs 大模型+提示词
完成"通用知识 / 专业咨询"二分类意图识别的对比实验（测试集 100 条，50/50）。

### 产出文件
- 训练数据：`rag_qa/intent_compare/data/train_200.jsonl`（200 条，100 通用 / 100 专业，deepseek-v4-flash 生成）
- 测试数据：`rag_qa/intent_compare/data/test_100.jsonl`（100 条，50/50，与训练集去重）
- BERT 微调模型：`rag_qa/core/bert_results/intent-ckpt`（基座 `bert_query_classifier`，原生 torch 循环微调，epoch3 val_acc=1.0）
- LLM 预测缓存：`rag_qa/intent_compare/data/llm_pred.jsonl`
- 对比报告：`rag_qa/intent_compare/data/report.json` + `report.md`

### 核心结果（测试集 100 条，50/50）
- BERT 微调：**准确率 0.9700**，Macro-F1 0.9700（通用 recall 0.98 / 专业 recall 0.96）
- 大模型+提示词（deepseek-v4-flash）：**准确率 0.8900**，Macro-F1 0.8887（通用全对，但专业咨询 recall 仅 0.78，11 条被误判通用知识）
- 结论：该分布下 BERT 微调明显优于 大模型+提示词（差 8 个点）。

### 关键坑与解决（重要，已同步到 MEMORY.md）
1. 本机无 torch → 在 managed python 3.13.12 建 venv：`C:/Users/lizhongxin/.workbuddy/binaries/python/envs/default`，装 torch(CPU)+transformers+sklearn+openai+numpy。
2. accelerate 在该 venv 下 `import` 即 Segmentation Fault → 改用原生 torch 训练循环（`train_intent.py`），不依赖 `Trainer`/`accelerate`。
3. Windows 上 transformers/OpenMP 多线程导致 segfault → 运行时设 `OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 TORCH_INTRA_OP_PARALLELISM=1`，代码内 `torch.set_num_threads(1)`。
4. `import rag_qa.core.query_classifier` 触发 `rag_qa/__init__` → 需 `milvus_model`（未装）→ 改用 `importlib.util.spec_from_file_location` 文件级加载该模块绕过包 `__init__`。
5. deepseek-v4-flash 对超短输入（如 "hi"）返回空串，但完整分类提示词下正常返回 JSON。

### 方法学注意
训练集(200)与测试集(100)同为 deepseek 生成的同分布数据，且测试生成模型=预测模型，存在分布自洽偏差（对 LLM 有利）；BERT 仍更高，说明在该分布上微调模型确实更强，但跨分布泛化需另测。
