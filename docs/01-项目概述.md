# 项目概述

> 黑马程序员智能问答系统（内部代号 **EduRAG**）——一个面向 IT 教育培训场景的 AI 问答系统。

## 1. 项目定位

本系统为「传智教育 / 黑马程序员」IT 培训业务提供智能答疑能力：学员提出课程、学费、知识点等相关问题后，系统自动给出准确回答。系统**融合两条回答链路**：

1. **精确问答链路（MySQL + BM25）**：对高频、标准问题做精确匹配，命中即直接返回，速度快、答案稳。
2. **检索增强生成链路（RAG）**：对需要结合知识库内容的问题，先做向量检索与重排序，再交给大模型生成答案。

两条链路由 **BERT 意图分类器** 自动分流：判断问题是「通用知识」还是「专业咨询」，前者直接交给大模型，后者走 RAG 检索增强流程。

## 2. 核心特性

| 特性 | 说明 |
|------|------|
| 双路召回 | MySQL/BM25 精确命中 + Milvus 向量 RAG，互补覆盖高频与长尾问题 |
| 意图分流 | BERT 微调二分类器（`通用知识` / `专业咨询`）决定走 LLM 直答还是 RAG |
| 多策略检索增强 | 直接检索 / HyDE 假设问题检索 / 子查询检索 / 回溯问题检索，由 LLM 动态选择 |
| 混合检索 + 重排 | BGE-M3 稠密 + 稀疏（BM25）向量混合检索，BGE-Reranker 重排序 |
| 对话历史记忆 | 最近 5 轮会话写入 MySQL `conversations` 表，RAG 生成时结合历史 |
| 流式输出 | Web 端通过 SSE（`/api/stream`）逐字返回，CLI 逐 token 打印 |
| 学科过滤 | 支持按学科（`ai`/`java`/`test`/`ops`/`bigdata`）过滤检索范围 |
| 多格式文档入库 | 支持 txt/pdf/docx/ppt/pptx/jpg/png/md，PDF/PPT/图片走 OCR 解析 |
| 可观测 | 统一日志（`base.logger`，文件 + 控制台）、RAGAS 评估、Locust 压测 |

## 3. 适用场景

- 学员课程咨询（大纲、学费、师资、校区等高频问题）→ BM25 精确命中
- 知识点答疑、跨文档综合问答 → RAG 检索增强
- 通用 IT 知识问答（如「5×9 等于几」）→ LLM 直答
- 内部培训仿真 / 客服辅助

## 4. 技术栈

| 分类 | 技术 |
|------|------|
| 语言 | Python 3.11+ |
| Web 框架 | FastAPI + Uvicorn，SSE 流式，WebSocket |
| 向量数据库 | Milvus 2.4（standalone，docker-compose 部署） |
| 嵌入模型 | BGE-M3（`milvus_model.BGEM3EmbeddingFunction`，稠密 1024 + 稀疏） |
| 重排模型 | BGE-Reranker-Large（`sentence-transformers.CrossEncoder`） |
| 意图分类 | BERT（`bert-base-chinese` 微调，`transformers`） |
| 关系/缓存库 | MySQL（`pymysql`）、Redis（`redis-py`） |
| 检索算法 | BM25（`rank_bm25`）+ jieba 分词 |
| 大模型 | DashScope 兼容接口（`openai` SDK），默认 `deepseek-v4-flash` |
| NLP / 文档 | LangChain、jieba、RapidOCR、python-pptx、PyMuPDF |
| 评估 / 压测 | RAGAS、Locust |

## 5. 入口程序一览

| 文件 | 作用 |
|------|------|
| `main.py` | 集成问答系统 CLI（MySQL + RAG + 历史），命令行交互 |
| `app.py` | FastAPI Web 服务（REST + SSE + 静态页 `static/index.html`） |
| `rag_qa/rag_main.py` | 独立 RAG 入口：数据处理模式（建索引）/ 交互查询模式 |
| `mysql_qa/sql_main.py` | 独立 MySQL BM25 问答 CLI |
| `locust_test.py` | 基于 Locust 的接口/WebSocket 性能压测 |
