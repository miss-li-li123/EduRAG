# 快速开始与部署

## 1. 环境要求

- Python 3.11+（依赖见 `requirements-windows.txt` / `requirements-mac.txt`）
- 可访问的 MySQL、Redis、Milvus（本机可用 Docker 一键拉起）
- 可用的 DashScope（阿里云）API Key（环境变量 `ALIYUN_API_KEY`）
- 已下载的本地模型：`rag_qa/models/bge-m3`、`bge-reranker-large`、意图 BERT 模型

## 2. 安装依赖

```bash
# 建议使用虚拟环境
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements-windows.txt
```

> 依赖较多（含 `torch`、`pymilvus`、`milvus-model`、`sentence-transformers`、`transformers` 等）。Mac 用户改用 `requirements-mac.txt`。

## 3. 配置

### 3.1 `config.ini`
按需修改各服务地址与参数（默认指向 `192.168.12.168` 的 MySQL/Redis/Milvus）：

```ini
[mysql]   host / user / password / database=subjects_kg
[redis]   host / port / password / db
[milvus]  host / port / database_name=itcast / collection_name=edurag
[llm]     model=deepseek-v4-flash ; dashscope_api_key 留空，用环境变量
[retrieval] parent_chunk_size / child_chunk_size / chunk_overlap / retrieval_k / candidate_m
[app]     valid_sources / customer_service_phone
```

### 3.2 环境变量（必须）
```bash
export ALIYUN_API_KEY="你的DashScope_API_Key"   # base/config.py 从此读取
```
> `config.ini` 中的 `dashscope_api_key` 字段为空，Key 必须通过环境变量注入。

## 4. 启动依赖（Milvus + Redis）

```bash
cd docker/milvus_redis
docker-compose up -d
```

包含 etcd、minio、milvus-standalone、redis 四个服务。首次启动会拉取镜像，请耐心等待 `milvus` 健康。

## 5. 构建知识库索引（离线）

将学科语料放入 `rag_qa/data/<学科>_data/`（如 `ai_data`），然后运行数据处理模式：

```bash
python -m rag_qa.rag_main   # 默认 query_mode=True（查询）
# 建索引需改为：
python -c "from rag_qa.rag_main import main; main(query_mode=False)"
```

脚本会遍历 `VALID_SOURCES` 各目录，分层切块并经 BGE-M3 写入 Milvus `edurag` 集合。

> 同时需将高频标准问答导入 MySQL `jpkb` 表（见 `mysql_qa/db/mysql_client.py` 的 `create_table` / `insert_data`，数据源 `mysql_qa/data/JP学科知识问答.csv`）。

## 6. 运行服务

### Web 服务（推荐）
```bash
uvicorn app:app --host 0.0.0.0 --port 8080
# 浏览器打开 http://localhost:8080
```
接口说明见 [05-API接口文档.md](./05-API接口文档.md)。

### 命令行交互
```bash
python main.py          # 集成问答（MySQL + RAG + 历史）
python -m mysql_qa.sql_main   # 仅 MySQL BM25 问答
```

## 7. 性能压测
```bash
locust -f locust_test.py --host http://localhost:8080
```
结果写入 `token_response_times.csv`。

## 8. 常见问题（FAQ）

| 现象 | 可能原因 / 处理 |
|------|------|
| `无法初始化语言模型客户端` | 未设置 `ALIYUN_API_KEY` 或 Base URL 不可达 |
| 导入 `rag_qa` 报缺 `milvus_model` | `vector_store.py` 顶层依赖，需装全量依赖 |
| Milvus 连接失败 | `docker-compose` 未启动，或 `config.ini` 的 milvus host/port 不对 |
| BM25 始终未命中 | MySQL `jpkb` 表无数据，或 Redis 缓存了空结果（清 Redis 重试） |
| `config.ini` 路径硬编码错误 | 代码写死了绝对路径，换机器需改 `base/config.py` |
| BERT 意图分类异常 | 确认 `bert_intent_cls` 指向正确的 2 分类意图模型（非 `checkpoint-87` 的 NER 模型） |

> 调优方向：检索阈值 `threshold=0.85`、重排权重 `WeightedRanker(1.0, 0.7)`、`CANDIDATE_M`、切分尺寸均可在 `config.ini` / `vector_store.py` 中调整。
