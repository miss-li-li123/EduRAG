# 模块说明

按目录逐模块说明职责、关键类与对外接口。

## 1. 基础层 `base/`

### `base/config.py` —— `Config`
读取 `config.ini`，集中暴露全部配置：
- MySQL / Redis / Milvus 连接参数
- LLM：`LLM_MODEL`（默认 `deepseek-v4-flash`）、`DASHSCOPE_BASE_URL`、`DASHSCOPE_API_KEY`（取自环境变量 `ALIYUN_API_KEY`）
- 检索参数：`PARENT_CHUNK_SIZE=1200`、`CHILD_CHUNK_SIZE=300`、`CHUNK_OVERLAP=50`、`RETRIEVAL_K=3`、`CANDIDATE_M=2`
- 应用：`VALID_SOURCES=["ai","java","test","ops","bigdata"]`、`CUSTOMER_SERVICE_PHONE`
- 模型路径：`nlp_bert_doc_seg`、`bert_intent_cls`（`rag_qa/core/bert_query_classifier`）

> 注意：`config.ini` 路径在代码中硬编码为绝对路径，部署到其它机器需同步修改。

### `base/logger.py` —— `logger`
统一日志器（名 `EduRAG`），INFO 级，文件（`logs/app.log`）+ 控制台双输出，避免重复 Handler。

## 2. 精确问答层 `mysql_qa/`

包导出：`MySQLClient`、`RedisClient`、`BM25Search`。

### `mysql_qa/db/mysql_client.py` —— `MySQLClient`
- `fetch_questions()`：取出 `jpkb` 表全部问题
- `fetch_answer(question)`：按问题取答案
- `create_table()` / `insert_data(csv_path)`：建表与导入 `JP学科知识问答.csv`
- `close()`：关闭连接

### `mysql_qa/cache/redis_client.py` —— `RedisClient`
- `set_data(key, value, expire)`：JSON 序列化存储，默认当天 23:00 过期
- `get_data(key)` / `get_answer(query)`：读取缓存答案（`answer:{query}`）

### `mysql_qa/utils/preprocess.py` —— `preprocess_text`
使用 `jieba.lcut` 做中文分词（转小写），供 BM25 使用。

### `mysql_qa/retrieval/bm25_search.py` —— `BM25Search`
- 构造时从 Redis 加载分词问题，缺失则从 MySQL 加载并回写 Redis
- `search(query, threshold=0.85)` → `(answer, need_rag)`：
  - 先查 Redis 答案缓存
  - BM25 打分 → Softmax 归一化 → 最高分 ≥ 阈值返回 MySQL 答案（`need_rag=False`）
  - 否则返回 `(None, True)`，表示需要走 RAG
- 同时维护 `sql_main.py`（`MySQLQASystem` CLI）

## 3. 检索增强层 `rag_qa/core/`

### `rag_qa/core/vector_store.py` —— `VectorStore`
- 初始化：加载 BGE-M3 嵌入、`bge-reranker-large` 重排器，连接 Milvus，自动建/载集合 `edurag`
- 集合字段：`id / text / dense_vector / sparse_vector / parent_id / parent_content / source / timestamp`
- `add_documents(docs)`：BGE-M3 生成稠密+稀疏向量，`upsert` 入库（id 为内容 md5）
- `hybrid_search_with_rerank(query, k, source_filter)`：
  - 稠密（IP）+ 稀疏（IP）双路 `AnnSearchRequest`，`WeightedRanker(1.0, 0.7)` 融合
  - 从子块还原去重父文档 → BGE-Reranker 重排 → 返回前 `CANDIDATE_M` 个父文档

### `rag_qa/core/query_classifier.py` —— `QueryClassifier`
- BERT 二分类意图识别：`通用知识`(0) / `专业咨询`(1)
- `predict_category(query)`：返回中文标签（默认 `通用知识`）
- 含训练/评估方法（`train_model` / `evaluate_model`），使用 `transformers.Trainer`

### `rag_qa/core/strategy_selector.py` —— `StrategySelector`
- `select_strategy(query)`：用 LLM 从「直接检索 / 假设问题检索(HyDE) / 子查询检索 / 回溯问题检索」择一（temperature=0.1，失败回退「直接检索」）

### `rag_qa/core/rag_system.py` —— `RAGSystem`（旧版，参考用）
非流式生成，历史由外部（`main.py`）维护。

### `rag_qa/core/new_rag_system.py` —— `RAGSystem`（**主链路使用**）
- `generate_answer(query, source_filter, history)`：生成器，逐 token yield
- 内部：BERT 分流 → 通用知识直答 / 专业咨询走策略选择 + `retrieve_and_merge` + RAG 提示词
- 支持历史拼接（最多 5 轮）、超长提示截断（`max_prompt_length=4096`）
- `retrieve_and_merge(query, source_filter, strategy)`：按策略路由到 HyDE / 子查询 / 回溯 / 直接检索

### `rag_qa/core/prompts.py` —— `RAGPrompts`
集中管理提示词：`rag_prompt`（含上下文/历史/问题/客服电话）、`hyde_prompt`、`subquery_prompt`、`backtracking_prompt`。

### `rag_qa/core/document_loader.py` & `document_processor.py`
- `load_documents_from_directory`：按扩展名选加载器（txt/pdf/docx/ppt/pptx/jpg/png/md），写入 `source`/`file_path`/`timestamp` 元数据
- `process_documents`：**父子块分层切分**（中文递归切分器 / Markdown 切分器），产出子块（带 `parent_id`/`parent_content`）

## 4. 文档解析与切分 `rag_qa/edu_document_loaders/` & `edu_text_spliter/`

- `edu_document_loaders/`：`OCRPDFLoader`、`OCRDOCLoader`、`OCRPPTLoader`、`OCRIMGLoader`（基于 RapidOCR）、`edu_docloader`、`edu_ocr`、`review` 等
- `edu_text_spliter/`：`ChineseRecursiveTextSplitter`、`AliTextSplitter`（中文友好的递归切分）

---

## 5. 模型与数据 `rag_qa/models/`、`rag_qa/data/`、`rag_qa/classify_data/`

- `models/`：`bge-m3`、`bge-reranker-large`、`nlp_bert_document-segmentation_chinese-base`（文档分段 NER 模型，**非意图模型**）
- `data/`：学科原始语料（`ai_data`、`samples`、`人工智能就业课课程大纲.md`）
- `classify_data/`：意图分类训练/生成数据（`training_data_1000.json` 等）、提示词、效果评估文档

---

## 6. 实验与评估 `rag_qa/intent_compare/`、`rag_qa/rag_assesment/`

- `intent_compare/`：**BERT 微调 vs 大模型+提示词 意图识别对比实验**（数据生成、训练、预测、评估报告）→ 详见 [06-意图识别对比实验.md](./06-意图识别对比实验.md)
- `rag_assesment/`：RAGAS 评估脚本与结果（`ragas_evaluate.py`、`ollama_ragas.py`、`rag_evaluate_data.json`）

| `locust_test.py` | `HttpUser` | `/api/query` 与 WebSocket 压测，结果写入 `token_response_times.csv` |
