# 意图识别对比实验：BERT 微调 vs 大模型 + 提示词

> 实验代码与完整数据位于 `rag_qa/intent_compare/`，完整报告见 `rag_qa/intent_compare/data/report.md` 与 `report.json`。

## 1. 实验目的

比较两条「通用知识 / 专业咨询」二分类技术路线在同一测试集上的准确率：
1. **BERT-base-chinese 微调模型**（轻量、本地、确定性强）
2. **大模型 + 提示词**（零样本，依赖 DashScope `deepseek-v4-flash`）

## 2. 实验设计

| 环节 | 做法 |
|------|------|
| 训练数据 | 调用 `deepseek-v4-flash` 生成 200 条（通用/专业各 100），存 `data/train_200.jsonl` |
| 测试数据 | 生成 100 条（50/50），与训练集去重，存 `data/test_100.jsonl` |
| BERT 基座 | `rag_qa/core/bert_query_classifier`（2 分类意图基座） |
| BERT 训练 | 原生 torch 训练循环（CPU，3 epoch），输出 `rag_qa/core/bert_results/intent-ckpt` |
| LLM 预测 | `deepseek-v4-flash` + 分类提示词，temperature=0，鲁棒解析 JSON/中文标签 |
| 评估 | 同一测试集上两方案各预测，输出准确率、Macro-F1、混淆矩阵、逐类 P/R/F1 |

## 3. 核心结果

测试集 100 条（通用知识 50 / 专业咨询 50）：

| 方法 | 准确率 | Macro-F1 |
|------|--------|----------|
| **BERT 微调**（`intent-ckpt`） | **0.9700** | 0.9700 |
| **大模型 + 提示词**（`deepseek-v4-flash`） | 0.8900 | 0.8887 |

**BERT 比大模型 + 提示词高 8 个百分点。**

### 混淆矩阵

**BERT**（行=真实，列=预测）
```
              通用知识   专业咨询
通用知识      [49,  1]
专业咨询      [ 2, 48]
```

**大模型 + 提示词**
```
              通用知识   专业咨询
通用知识      [50,  0]
专业咨询      [11, 39]
```

## 4. 结论与解读

- **BERT 两类都很稳**（recall 0.96~0.98），错误极少。
- **大模型 + 提示词**对「通用知识」全对，但 **11 条专业咨询被误判为通用知识**（专业类 recall 仅 0.78）——大模型倾向把问题当作「通用知识」直答，漏走 RAG。
- 在该分布上，微调小模型在准确率与稳定性上均优于零样本大模型，且推理成本更低、可本地化。

## 5. 方法学注意事项（重要）

- 训练集（200）与测试集（100）均由 `deepseek-v4-flash` 生成，属**同分布**；且「生成测试集」与「做预测」使用同一模型家族，存在分布自洽偏差（对 LLM 反而更有利）。但 BERT 仍明显胜出，说明结论稳健。
- 若需更严谨的泛化验证，建议：
  1. 用**不同模型家族**生成测试集（如 qwen 生成、deepseek 预测，或反之）；
  2. 补充一批**真实业务 / 人工标注**问题做交叉验证。

## 6. 复现步骤

```bash
# 1. 生成数据（需 ALIYUN_API_KEY）
python rag_qa/intent_compare/gen_data.py --train_n 200 --test_n 100
# 2. 微调 BERT（原生训练循环，无需 accelerate）
python rag_qa/intent_compare/train_intent.py
# 3. 大模型预测（逐条落盘）
python rag_qa/intent_compare/llm_predict.py
# 4. 统一对比并生成报告
python rag_qa/intent_compare/eval_compare.py
```

产出：`data/train_200.jsonl`、`data/test_100.jsonl`、`data/llm_pred.jsonl`、`data/report.md`、`data/report.json`，以及模型 `rag_qa/core/bert_results/intent-ckpt/`。
