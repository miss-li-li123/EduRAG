# 目录结构与文件清单

项目根：`D:/code/PythonProject/Itcast_qa_system`

```
Itcast_qa_system/
├── main.py                      # 集成问答 CLI（MySQL+RAG+会话历史）
├── app.py                       # FastAPI Web 服务（REST+SSE+静态页）
├── config.ini                   # 全局配置（mysql/redis/milvus/llm/retrieval/app/logger）
├── locust_test.py               # Locust 压测脚本
├── requirements-windows.txt     # Windows 依赖清单
├── requirements-mac.txt         # macOS 依赖清单
├── README.md                    # 项目说明（见 docs/）
├── base/                        # 基础层
│   ├── config.py                # Config：读取 config.ini + 环境变量
│   └── logger.py                # 统一日志器
├── mysql_qa/                    # 精确问答层（BM25）
│   ├── __init__.py              # 导出 MySQLClient/RedisClient/BM25Search
│   ├── sql_main.py              # MySQL 问答 CLI
│   ├── db/mysql_client.py       # MySQL 连接与 jpkb 表操作
│   ├── cache/redis_client.py    # Redis 缓存
│   ├── retrieval/bm25_search.py # BM25 检索（阈值 0.85）
│   ├── utils/preprocess.py      # jieba 分词
│   └── data/JP学科知识问答.csv   # 高频标准问答数据源
├── rag_qa/                      # 检索增强层（RAG）
│   ├── __init__.py              # 导出 VectorStore(new)/RAGSystem(new)
│   ├── rag_main.py              # 独立 RAG 入口（建索引/查询）
│   ├── core/
│   │   ├── vector_store.py      # Milvus 向量库 + BGE-M3 混合检索 + 重排
│   │   ├── rag_system.py        # RAGSystem（旧版，参考）
│   │   ├── new_rag_system.py    # RAGSystem（主链路：流式+历史）
│   │   ├── strategy_selector.py # LLM 检索策略选择
│   │   ├── query_classifier.py  # BERT 意图分类
│   │   ├── document_loader.py   # 多格式文档加载
│   │   ├── document_processor.py# 父子块分层切分
│   │   ├── prompts.py           # 提示词模板
│   │   ├── bert_query_classifier/  # 意图 BERT 基座
│   │   ├── bert_outputs/        # 旧训练输出
│   │   └── bert_results/        # 训练结果（含 intent-ckpt）
│   ├── edu_document_loaders/    # OCR 文档加载器（PDF/DOC/PPT/IMG）
│   ├── edu_text_spliter/        # 中文递归切分器
│   ├── models/                  # 本地模型（bge-m3 / bge-reranker-large / bert-doc-seg）
│   ├── data/                    # 学科语料（ai_data 等）
│   ├── classify_data/           # 意图分类数据/提示词/评估
│   ├── intent_compare/          # 意图识别对比实验（见 06）
│   │   ├── gen_data.py / train_intent.py / llm_predict.py / eval_compare.py
│   │   └── data/                # 训练/测试数据/预测/报告
│   └── rag_assesment/           # RAGAS 评估
├── docker/
│   └── milvus_redis/
│       └── docker-compose.yml   # Milvus + Redis 一键部署
├── static/                      # 前端页面（index.html + src）
├── notebooks/                   # 探索性 notebook（bert/bge/milvus/redis 等）
├── logs/                        # 运行日志（app.log）
└── docs/                        # ← 本文档集合（本目录为本次新增）
    ├── README.md                # 文档导航
    ├── 01-项目概述.md
    ├── 02-系统架构.md
    ├── 03-模块说明.md
    ├── 04-快速开始与部署.md
    ├── 05-API接口文档.md
    ├── 06-意图识别对比实验.md
    └── 07-目录结构与文件清单.md
```
